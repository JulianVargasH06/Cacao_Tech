# Evidencias

Capturas de pantalla que muestran el cumplimiento de los requisitos del informe final de CacaoTech.

## Cómo nombrar las capturas

`<requisito>-<descripción-corta>.png`, en minúsculas y con guiones, por ejemplo:

- `hu01-recepcion-lote-valido.png`
- `hu04-alerta-merma-20.png`
- `prueba-06-respaldo-restaurado.png`

Así quedan ordenadas por requisito y es fácil citarlas desde el informe.
